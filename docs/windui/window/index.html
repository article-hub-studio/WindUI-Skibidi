Dynamic Island Open Button

EditOpenButton returns a controller. Its width, height, icon, title, and content animate between four states without recreating the UI. After AutoHide seconds, the button contracts into the small Idle pill while remaining tappable. When MorphWindow is enabled, closing the window keeps its layout intact while the whole surface scales down and travels into the Dynamic Island; opening reverses the same animation.

Every part of the pill travels on one clock, so the label, drag handle and divider move with the container instead of snapping ahead of it. The pill sizes itself from the font it actually renders with, including a font swapped in later through WindUI:SetFont, so a long Title widens the island rather than being truncated. State changes honour WindUI:SetReducedMotion(true) and apply instantly.

Window Types

A window type is a bundle of surface, spacing and topbar defaults. Pass one instead of hand-tuning a dozen fields:

Anything you pass explicitly wins over the preset, so you can start from a type and adjust:

Names are case-insensitive and ignore spaces, dashes and underscores, so "Modern", "liquid-glass" and "Liquid Glass" all resolve. An unrecognised name warns in the console and leaves your config untouched.

TypeAliasesLook
moderncard, cards, flatFlat near-black cards (#131617 panel, #1D2022 card) separated by 10px gaps, 18px element radius, 24px window radius, Mac topbar, and the lime #A2FF31 accent from the Modern theme.
glassliquid, liquidglass, acrylicTranslucent liquid-glass elements welded into one column by linked corners. This is what modern looked like before the rework.
defaultclassic, legacy, originalThe original WindUI look: opaque elements, 8px gaps, 16px radius, standard topbar.

modern and glass set Theme for you (Modern for modern) only when you have not chosen one yourself.

Advanced Linked Corners

Linked corners use Roblox's native per-corner UICorner radii, so every element surface—not only the outer container—receives the correct top-left, top-right, bottom-left and bottom-right shape. Sequences can split by group or explicit breaks, and HStack automatically switches linking direction when it stacks vertically.

Tabs and containers such as Group, HStack, and VStack may define their own CornerLink table. InnerRadius = 0 uses native per-corner radii to keep every shared seam completely flat. Gap = 0 joins surfaces edge-to-edge and Gap = 1 leaves a crisp separator. Individual elements support CornerGroup, CornerBreak, CornerBreakBefore, CornerBreakAfter, and LinkCorners = false.

Background API

SetBackgroundImage still works, but new code should use SetBackground. It accepts colors, gradients, images, custom assets and .webm videos.

Loading API

Use the standalone loading API when the loading screen should live outside CreateWindow. LoadingScreen in the window config still works for older scripts.
